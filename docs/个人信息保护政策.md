## 一、我们如何收集与使用个人信息

为实现导师入驻审核、家长/学员注册匹配、约课履约、资金托管结算及可选 IoT 教学仓服务，我们可能在征得同意或依法具备其他合法性基础的情况下处理下列信息：

### 1. 账号与实名信息

- 手机号码、验证码、登录凭证；
- 姓名、证件类型与号码（用于实名核验）；
- 导师侧可能还包括学籍/学历相关核验信息、结算用银行账户信息（卡号脱敏展示、开户行等）。

**目的**：注册登录、身份核验、防欺诈、满足监管与结算要求。

### 2. 学情与匹配信息（家长/学员）

- 学员昵称/称谓、年级、目标学科、学习诉求与节奏偏好等您主动填写的信息。

**目的**：建立辅导档案、匹配导师、优化约课体验。

### 3. 约课与履约信息

- 预约时段、请假/改期记录、到课签到、课后核销、教学仓（如有）门禁或通电相关日志。

**目的**：履行约课合同、争议举证、空间安全与运营统计。

### 4. 交易与托管相关信息

- 订单金额、冻结/解冻状态、支付通道回执、分成划拨结果等。

**目的**：完成「一课一消」托管结算、对账与售后处理。

### 5. 设备与日志信息

- 大致包括设备型号、操作系统、浏览器类型、IP 地址、崩溃日志、操作日志等。

**目的**：保障服务安全稳定、排查故障、预防攻击与滥用。

### 6. 客服与反馈信息

- 您与客服沟通时提供的内容、凭证材料。

**目的**：响应咨询、投诉与争议协调。

我们不会以欺骗、误导方式收集个人信息，也不会因您拒绝提供非必要信息而拒绝提供基本功能，但可能无法使用依赖该信息的特定服务（例如无法完成实名入驻或托管结算）。

## 二、个人信息的使用规则

我们仅在本政策所述目的范围内使用个人信息，包括：

1. 向您提供、维护、改进平台核心功能；
2. 发送与服务相关的通知（约课提醒、请假确认、资金状态等）；
3. 开展安全风控、审计与合规报送（在法律要求范围内）；
4. 在匿名化、去标识化处理后用于统计分析与产品优化。

未经您的同意，我们不会将个人信息用于与本政策无关的营销推送；如后续开展，将另行征得同意。

## 三、存储地点、方式与期限

1. **存储地点**：原则上存储于中华人民共和国境内。如确需跨境，将依法履行告知同意或安全评估等义务（演示产品默认不跨境）。
2. **存储方式**：采取加密、访问控制等合理技术与管理措施。
3. **存储期限**：在实现处理目的所必需的最短时间内保存；超过期限后删除或匿名化。因法律、会计、反洗钱或争议解决需要的，可在必要期限内继续保存。
4. 账号注销后，我们将按法律规定删除或匿名化相关信息，但依法需留存的除外。

## 四、共享、转让、公开披露与委托处理

1. **共享**：原则上不向第三方共享您的个人信息。以下情形除外：
   - 获得您的单独同意；
   - 为实现托管结算，与合作商业银行/支付机构共享必要的交易与身份一致性信息；
   - 为完成公安实名、学信核验等依法开展的核验，向合法核验接口提供必要字段；
   - 根据法律法规或行政机关、司法机关依法提出的要求。
2. **转让**：涉及合并、分立、收购等时，我们会要求承继方继续受本政策约束，并依法告知您。
3. **公开披露**：不会公开披露您的个人信息，法律另有规定或获得您同意的除外。
4. **委托处理**：可能委托云服务、短信、客服系统等供应商处理必要信息，并签订数据处理条款、要求其不得用于约定以外目的。

我们不会出售您的个人信息。

## 五、反洗钱与资金清算授权（专节）

为落实反洗钱、反恐怖融资及商业银行资金存管监管要求，并完成课酬冻结与划拨，在您使用支付/结算功能时：

1. 您理解并同意，平台及合作银行/支付机构可在最小必要范围内核验姓名、证件号、银行账户等一致性信息；
2. 您授权对交易流水、冻结与解冻记录进行留存与调阅，期限符合金融监管与反洗钱规定；
3. 如监测到可疑交易，合作机构或平台可依法暂停结算、要求补充说明或向有权机关报告；
4. 本专节是《个人信息保护政策》的组成部分，登录页所称《个人信息保护政策》已涵盖本授权内容；专项资金规则仍以《资金托管与服务协议》等页面协议为准。

## 六、您的权利

在适用法律范围内，您有权：

1. 查阅、复制您的个人信息；
2. 更正、补充不准确或不完整的信息；
3. 删除依法可删除的信息；
4. 改变授权同意范围或撤回同意（不影响撤回前基于同意的处理）；
5. 注销账号；
6. 获取个人信息转移的合法协助（如适用）；
7. 对自动化决策提出拒绝或说明请求（如适用）。

您可通过平台内反馈入口或本政策载明的联系方式提出请求。我们将在核实身份后合理期限内答复。为保障安全，可能需要您提供必要证明。

## 七、未成年人保护

1. 平台服务涉及中小学科学情辅导场景，学员多为未成年人。我们要求由父母或其他监护人注册、约课并行使相关权利。
2. 处理不满十四周岁未成年人的个人信息，将依法征得监护人同意，并仅在未成年人权益所必要的范围内处理。
3. 监护人如发现我们在未经同意情况下收集了未成年人信息，请及时联系我们，我们将尽快删除（法律另有规定的除外）。

## 八、Cookie 与同类技术

为维持登录态、记住偏好与分析访问情况，我们可能使用 Cookie 或本地存储等同类技术。您可以通过浏览器设置管理 Cookie；拒绝可能影响部分功能可用性。演示环境中的统计能力可能简化或关闭。

## 九、安全措施

我们采取包括但不限于传输加密、存储加密、权限分级、安全审计、员工保密义务等措施保护个人信息。但请理解，任何安全措施都无法做到绝对安全。如发生或可能发生个人信息安全事件，我们将按法律要求告知您并上报监管部门（如适用），并采取补救措施。

## 十、本政策的更新
