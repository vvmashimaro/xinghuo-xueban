# 星火伴学 · 导师教研评级内部量规（运营版）

> **适用范围**：管理端「导师审核」与教研复核；仅供运营、教研与风控内部使用，不对家长端展示维度备注。  
> **版本**：v1.0 · 2026-10  
> **定级字段**：`evalGrade`（综合等级）+ `evalRubricNotes`（分维度备注，可选）

---

## 一、评级等级（综合定级 `evalGrade`）

| 等级代码 | 展示名称 | 适用场景 | 平台策略摘要 |
|---------|---------|---------|-------------|
| **待教研评级** | 待教研评级 | 新提交入驻、尚未完成试讲/材料审 | 不对家长推荐；审核队列优先处理 |
| **V1** | V1 级标准导师 | 资质齐备、试讲达标、可承担常规学科辅导 | 可匹配、可展示；时薪建议区间中位 |
| **V2** | V2 级金牌导师 | 试讲优秀、学科深度与表达均突出 | 优先匹配高意向家长；可参与专题课 |
| **V3** | V3 级首席导师 | 顶尖院校/竞赛背景、试讲与案例均属标杆 | 限量展示；高难学科与冲刺场景首选 |
| **待复评** | 待复评 | 补件后需二次审、或敏感信息变更后 | 暂停新单匹配直至复评完成 |
| **不予评级** | 不予评级 | 驳回或严重合规问题 | 不得入库展示；保留审计记录 |

**定级原则**：综合等级取「木桶短板」——任一核心维度未达 V1 底线时，不得定为 V2/V3；存在重大合规/安全风险时，直接「不予评级」或维持「待复评」。

---

## 二、评价维度与 1–4 分档（内部打分参考）

各维度采用 **1（不达标）— 4（标杆）** 四分制，用于审核表单备注与合议记录；**不强制录入数值**，运营可在备注中写「约 3 分」等自然语言。综合定级时建议：**四维均 ≥3 且无 1 分** → 可考虑 V2；**三维为 4 且资质无瑕疵** → 可提名 V3。

### 维度 A · 资质与合规（credential）

| 分值 | 描述 | 观测证据 |
|-----|------|---------|
| 4 | 学信网/教资等核验一致，证件齐全且在有效期内 | 管理端学籍截图、教资编号、无敏感变更待审 |
| 3 | 学籍清晰，教资或等价证明缺一但可补 | 补件清单明确、时限可控 |
| 2 | 材料模糊、学籍存疑或曾虚假申报 | 需补件或人工外呼核实 |
| 1 | 造假、冒用身份或拒绝提供必要证明 | 直接驳回，不予评级 |

### 维度 B · 试讲与授课表现（demo）

| 分值 | 描述 | 观测证据 |
|-----|------|---------|
| 4 | 结构完整（目标—讲解—练习—小结），板书/演示规范，能启发思考 | 5–10 分钟试讲视频，解题步骤可跟 |
| 3 | 讲解清楚，节奏适中，偶有口误或互动不足 | 可上岗 V1 |
| 2 | 照本宣科、超时严重或目标不清 | 建议补拍试讲或降级 V1 |
| 1 | 内容错误、态度不当或无法完成基本授课 | 不予评级或驳回 |

### 维度 C · 学科专业度（subject）

| 分值 | 描述 | 观测证据 |
|-----|------|---------|
| 4 | 申报学段/学科与院校专业高度匹配，能讲清考点与常见误区 | 成绩单、竞赛/科研经历、家长评价（如有） |
| 3 | 能覆盖申报学科核心考点，深度一般 | 标准 V1/V2 主力 |
| 2 | 学科跨度大但证据不足 | 限制学科标签或降时薪档 |
| 1 | 明显不具备申报学科辅导能力 | 不予评级或仅保留与专业无关标签 |

### 维度 D · 沟通与服务意识（communication）

| 分值 | 描述 | 观测证据 |
|-----|------|---------|
| 4 | 用语专业、尊重边界，能说明请假/改期与课后反馈机制 | 入驻问卷、试讲旁白、历史客诉为零 |
| 3 | 沟通正常，无红线 | 默认通过 |
| 2 | 响应慢、承诺模糊 | 入库时备注，运营跟进首单 |
| 1 | 辱骂、歧视、私下交易引导等 | 不予评级，必要时拉黑 |

### 维度 E · 安全与履约风险（safety）

| 分值 | 描述 | 观测证据 |
|-----|------|---------|
| 4 | 无违规记录，接受平台仓内授课与资金托管 | 合约与历史履约良好 |
| 3 | 新导师，无负面记录 | 正常监控 |
| 2 | 曾有迟到/无故拒单 | 限制接单或强制复训 |
| 1 | 人身安全、未成年人保护或资金安全风险 | 立即下架，不予评级 |

## 三、定级决策树（简版）

```text
开始审阅案卷
  ├─ 资质/安全任一 = 1 → evalGrade = 不予评级（或 rejected）
  ├─ 待补材料 → evalGrade = 待复评，status = supplement
  ├─ 四维均 ≥3，试讲 ≥3 → 默认 V1；试讲=4 且两维=4 → 可 V2
  ├─ 三维=4 且资质=4 且学科=4 → 提名 V3（需教研负责人二次确认）
  └─ 仅保存备注未改等级 → 维持原 evalGrade，更新 evalRubricNotes
```

## 四、系统字段映射（管理端）

| UI 区域 | 持久化字段 | 说明 |
|--------|-----------|------|
| 教研定级下拉 | `evalGrade` | 上表「展示名称」之一 |
| 分维度备注文本框 | `evalRubricNotes.credential` 等 | 键名与维度 B–E 的 `key` 一致 |
| 审核意见 | `reviewComment` | 家长不可见；可与定级结论一并保存 |

**与审核动作关系**：

- 「通过入库」：若定级仍为「待教研评级」，系统可默认升为 **V2 级金牌导师**（可在保存定级后覆盖）。
- 「待补材料 / 驳回」：建议同步将定级设为 **待复评** 或 **不予评级**，并在对应维度备注写明原因。

## 五、质量与校准

- **抽检**：每月随机 10% 新入库导师，教研组长对照本量规复核，偏差 &gt;1 档的个案需复盘。
- **申诉**：导师对定级异议走「待复评」通道，备注中须引用本量规维度与证据链接。
- **修订**：量规变更须更新本文版本号，并在管理端发布说明；历史 `evalRubricNotes` 保留只读。
